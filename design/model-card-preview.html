模型池卡片 · 能力标签修复预览

对照组：修复前的能力标签不可辨识 —— 修复后统一走全站徽标规范，深浅色一致。

根因：能力标签原先用 <NTag :type="capabilityColor(cap)">，而 capabilityColor() 返回 purple / blue / green / orange / pink。 Naive UI 的 Tag 主题只定义了 default / primary / info / success / warning / error 六组颜色变量， 其它取值取不到颜色 —— 标签因此退化成不可辨识的填充块。
修法：能力标签改用全站统一的 .s-badge（基类自带中性配色），颜色只来自设计令牌， 深浅色自动跟随；同时给 .s-badge 补上默认底色，避免裸用徽标退化成纯文字。

徽标基类一览

裸用（默认中性） neutral accent success warn danger

基类现在自带「底色 + 描边 + 文字色」，因此不加色调修饰符也不会变成隐形文字； 色调类只覆盖颜色，不改形状。能力标签属于「类别」而非「状态」，统一用 neutral， 让颜色只承载状态语义（健康 / 告警 / 错误）。
