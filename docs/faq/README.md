## 安装问题

### Q: Windows 安装时提示"Windows 已保护你的电脑"

**A**: 这是因为应用未签名。解决方法：
1. 点击"更多信息"
2. 点击"仍要运行"
3. 按照安装向导完成安装

### Q: macOS 提示"无法打开，因为无法验证开发者"

**A**: 解决方法：
1. 打开"系统偏好设置" → "安全性与隐私"
2. 在"通用"标签页，点击"仍要打开"
3. 或者右键点击应用，选择"打开"

### Q: Linux 安装依赖缺失

**A**: 安装必要依赖：
```bash
# Ubuntu/Debian
sudo apt-get install libwebkit2gtk-4.0-37 libgtk-3-0

# Fedora
sudo dnf install webkit2gtk3 gtk3
```

### Q: 安装后无法启动

**A**: 可能原因及解决方案：
1. **端口被占用**: 检查 7600 端口是否被其他程序占用
2. **权限不足**: 以管理员权限运行
3. **缺少运行时**: 安装 Visual C++ Redistributable (Windows)

## 配置问题

### Q: 如何获取 API Key？

**A**: 各服务获取方式：
- **OpenAI**: https://platform.openai.com/api-keys
- **Claude**: https://console.anthropic.com/
- **Gemini**: https://makersuite.google.com/app/apikey
- **DeepSeek**: https://platform.deepseek.com/

### Q: 可以同时配置多个 API Key 吗？

**A**: 可以。在提供商管理中，您可以：
- 为每个服务配置多个 Key
- 系统会自动轮换使用
- 单个 Key 失效不影响其他 Key

### Q: 配置保存在哪里？

**A**: 配置文件位置：
- **Windows**: `%APPDATA%\silk\config.json`
- **macOS**: `~/Library/Application Support/silk/config.json`
- **Linux**: `~/.config/silk/config.json`

### Q: 如何备份配置？

**A**: 方法：
1. 复制上述配置文件
2. 或使用应用内的"导出配置"功能
3. 恢复时导入或覆盖配置文件

### Q: 引导向导可以跳过吗？

**A**: 可以。点击"跳过"按钮，稍后在"设置"中手动配置。

## 使用问题

### Q: 支持哪些AI应用？

**A**: 支持所有兼容 OpenAI API 格式的应用，包括：
- ChatGPT-Next-Web
- Cursor
- Continue
- LobeChat
- ChatBox
- 等等

### Q: 如何在应用中配置 Silk？

**A**: 通用配置方法：
```
API地址: http://127.0.0.1:7600/v1/chat/completions
API Key: 您的API Key（任意一个已配置的）
```

### Q: 响应返回 401 错误

**A**: 可能原因：
1. API Key 不正确
2. API Key 已过期
3. 服务账户余额不足

解决方法：
1. 检查 API Key 是否正确
2. 在提供商管理中更新 API Key
3. 检查服务账户状态

### Q: 响应返回 429 错误

**A**: 表示请求频率过高。解决方法：
1. 等待一段时间后重试
2. 配置多个服务实现负载均衡
3. 升级服务套餐

### Q: 响应速度很慢

**A**: 可能原因及解决：
1. **网络问题**: 检查网络连接
2. **服务繁忙**: 切换到其他服务
3. **模型选择**: 使用较小的模型（如 gpt-3.5-turbo）

### Q: 如何查看请求日志？

**A**: 
1. 打开应用
2. 点击左侧"日志"菜单
3. 可以按时间、状态码筛选

### Q: 支持流式响应吗？

**A**: 支持。在请求中添加 `"stream": true` 即可。

## 性能问题

### Q: 内存占用过高

**A**: 解决方法：
1. 减少同时运行的服务数量
2. 定期重启应用
3. 更新到最新版本

### Q: CPU 占用率高

**A**: 可能原因：
1. 大量并发请求
2. 日志记录过多

解决方法：
1. 降低请求并发数
2. 调整日志级别

### Q: 响应延迟高

**A**: 优化建议：
1. 选择地理位置近的服务
2. 使用更快的网络
3. 减少请求体大小

## 安全问题

### Q: API Key 是否安全？

**A**: 是的。Silk 采取以下安全措施：
- API Key 本地存储，不上传云端
- 使用系统加密存储
- 内存中不持久化敏感信息

### Q: 请求数据是否加密？

**A**: 
- 本地通信: HTTP（仅本地访问）
- 与AI服务通信: HTTPS（加密传输）

### Q: 是否会收集用户数据？

**A**: 不会。Silk 完全本地运行，不收集任何用户数据。

### Q: 如何确保安全使用？

**A**: 建议：
1. 不要暴露本地端口到公网
2. 定期更新 API Key
3. 使用强密码保护配置文件
4. 及时更新应用版本

## 更新问题

### Q: 如何更新到最新版本？

**A**: 
1. 应用内检查更新
2. 或从官网下载最新版本
3. 覆盖安装即可

### Q: 更新后配置会丢失吗？

**A**: 不会。配置文件独立于应用，更新不会影响。

### Q: 如何查看当前版本？

**A**: 
1. 打开应用
2. 点击"帮助" → "关于"
3. 或查看启动画面
