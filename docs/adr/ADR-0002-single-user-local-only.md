# ADR-0002: 单用户本地专用设计

> 状态：Accepted | 日期：2026-08-27

## 背景

Silk 定位为个人本地桌面应用，需要明确架构边界。

## 决策

- **不做**：多用户、Web 后台、云端同步、分布式、Redis、消息队列
- **不做**：独立 API Key 管理功能（本地个人使用不需要）
- **做**：纯本地 SQLite 存储、AES-GCM 加密密钥、SHA-256 哈希网关 Key
- **做**：系统托盘驻留、开机自启、最小化后台

## 后果

- 正面：架构简单、无运维负担、数据完全私有
- 负面：无法多人协作、无法远程管理（除非开启 remote_access 并承担安全风险）
