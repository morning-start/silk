## 快速开始

### 1. 启动应用

双击 Silk 图标启动应用。首次启动时会显示：
- 启动画面（显示加载进度）
- 引导向导（帮助您完成初始配置）

### 2. 配置AI服务

在引导向导中：
1. 选择您要使用的AI服务（如 OpenAI、Claude 等）
2. 输入对应的 API Key
3. 点击"开始使用"

### 3. 开始使用

配置完成后，您可以在任何支持 OpenAI 格式的应用中使用 Silk：

```
API地址: http://127.0.0.1:7600/v1/chat/completions
API Key: 您配置的任意一个API Key
```

## 安装说明

### Windows

1. 下载 `Silk_x.x.x_x64-setup.exe`
2. 运行安装程序
3. 按照提示完成安装

### macOS

1. 下载 `Silk_x.x.x_x64.dmg`
2. 打开 DMG 文件
3. 将 Silk 拖入 Applications 文件夹

### Linux

1. 下载 `Silk_x.x.x_amd64.deb` 或 `.AppImage`
2. 安装：`sudo dpkg -i silk_x.x.x_amd64.deb`

## 首次配置

### 引导向导

引导向导包含3个步骤：

#### 步骤1：选择AI服务

系统会自动检测您已安装的AI应用。您也可以手动选择：

| 服务 | 说明 |
|------|------|
| OpenAI | GPT-4, GPT-3.5-turbo 等 |
| Claude | Anthropic Claude 系列 |
| Gemini | Google Gemini 系列 |
| 文心一言 | 百度文心一言 |
| 通义千问 | 阿里通义千问 |
| DeepSeek | DeepSeek AI |

#### 步骤2：配置API Key

为选择的服务输入 API Key。您可以：
- 一次性配置所有服务
- 先配置部分服务，稍后再添加

#### 步骤3：完成

显示配置摘要和快速使用指南。

### 手动配置

跳过引导向导后，您可以在"设置"页面手动配置：

1. 点击左侧菜单"设置"
2. 选择"提供商管理"
3. 点击"添加提供商"
4. 填写配置信息

## 日常使用

### 查看状态

主界面显示：
- 网关运行状态（绿色=运行中，红色=已停止）
- 已配置的服务数量
- 快捷操作按钮

### 启动/停止网关

点击"启动网关"或"停止网关"按钮控制服务。

### 快捷操作

主界面提供以下快捷操作：
- **启动全部服务** - 一键启动所有已配置的服务
- **停止全部服务** - 一键停止所有服务
- **测试连接** - 测试所有服务的连接状态

### 查看日志

1. 点击左侧菜单"日志"
2. 可以筛选：
   - 请求/响应日志
   - 错误日志
   - 按时间范围筛选

### 管理配置

在"设置"页面可以：
- 添加/删除提供商
- 修改 API Key
- 调整高级设置（超时、重试等）

## 配置示例

### 在 ChatGPT-Next-Web 中使用

1. 打开 ChatGPT-Next-Web 设置
2. 填写：
   - API Proxy URL: `http://127.0.0.1:7600`
   - API Key: 您的 API Key
3. 保存并开始对话

### 在 Cursor 中使用

1. 打开 Cursor 设置
2. 找到 OpenAI API 配置
3. 填写：
   - API Base URL: `http://127.0.0.1:7600/v1`
   - API Key: 您的 API Key
4. 选择模型并开始使用

### 在 Continue 中使用

配置 `~/.continue/config.json`：

```json
{
  "models": [{
    "title": "GPT-4",
    "provider": "openai",
    "model": "gpt-4",
    "apiBase": "http://127.0.0.1:7600/v1"
  }]
}
```

## 故障排除

### 无法启动网关

**问题**: 点击"启动网关"后显示错误

**解决方案**:
1. 检查端口 7600 是否被占用
2. 以管理员权限运行
3. 检查防火墙设置

### API调用失败

**问题**: 调用API返回错误

**解决方案**:
1. 检查 API Key 是否正确
2. 检查网络连接
3. 查看错误日志获取详细信息

### 响应速度慢

**问题**: AI响应明显变慢

**解决方案**:
1. 检查网络连接质量
2. 尝试切换到其他服务
3. 检查是否触发了速率限制

### 常见错误码

| 错误码 | 含义 | 解决方案 |
|--------|------|----------|
| 401 | 认证失败 | 检查 API Key |
| 429 | 请求过多 | 等待或切换服务 |
| 500 | 服务器错误 | 查看日志 |
| 503 | 服务不可用 | 稍后重试 |
