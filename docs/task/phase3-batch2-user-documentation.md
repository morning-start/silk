# Silk 用户手册

## 1. 简介

Silk 是您的个人AI总机，让您在一个地方访问所有AI服务。

### 1.1 主要功能

- **统一访问**：一个入口访问所有AI服务
- **智能路由**：自动选择最佳AI服务
- **协议转换**：支持多种AI协议
- **本地代理**：安全的本地数据处理
- **请求日志**：记录所有AI请求

### 1.2 支持的AI服务

- OpenAI (ChatGPT)
- Claude
- Google Gemini
- 文心一言
- 通义千问
- DeepSeek
- 以及其他兼容OpenAI API格式的服务

## 2. 安装指南

### 2.1 系统要求

- **操作系统**：Windows 10+, macOS 10.15+, Ubuntu 18.04+
- **内存**：4GB+
- **磁盘空间**：100MB+

### 2.2 下载安装

#### Windows

1. 访问 [Silk官网](https://silk.dev) 下载Windows版本
2. 双击运行安装程序
3. 按照提示完成安装
4. 启动Silk应用

#### macOS

1. 访问 [Silk官网](https://silk.dev) 下载macOS版本
2. 打开下载的 `.dmg` 文件
3. 将Silk拖到Applications文件夹
4. 首次运行时，右键点击选择"打开"

#### Linux

1. 访问 [Silk官网](https://silk.dev) 下载Linux版本
2. 解压下载的文件
3. 运行 `./silk` 命令

### 2.3 首次启动

1. 启动Silk应用
2. 等待启动画面完成
3. 按照引导页提示完成初始配置
4. 开始使用Silk

## 3. 快速开始

### 3.1 添加AI服务

1. 点击左侧菜单的"AI服务"
2. 点击"添加服务"按钮
3. 选择您要使用的AI服务（如OpenAI、Claude等）
4. 输入API密钥
5. 点击"保存"完成添加

### 3.2 获取API密钥

#### OpenAI

1. 访问 [OpenAI Platform](https://platform.openai.com/api-keys)
2. 登录您的账户
3. 点击"Create new secret key"
4. 复制生成的API密钥

#### Claude

1. 访问 [Anthropic Console](https://console.anthropic.com/api-keys)
2. 登录您的账户
3. 点击"Create Key"
4. 复制生成的API密钥

#### 其他服务

请参考各服务的官方文档获取API密钥。

### 3.3 启动网关

1. 在仪表盘页面，点击"启动网关"按钮
2. 等待网关启动成功
3. 记录显示的本地地址（如 `http://127.0.0.1:1877`）

### 3.4 配置AI客户端

在您的AI客户端中，将API地址设置为Silk的地址：

- **ChatGPT客户端**：设置API地址为 `http://127.0.0.1:1877/v1/chat/completions`
- **Claude客户端**：设置API地址为 `http://127.0.0.1:1877/v1/messages`
- **其他客户端**：参考客户端文档设置API地址

## 4. 功能介绍

### 4.1 仪表盘

仪表盘显示以下信息：

- **网关状态**：显示网关是否运行中
- **请求统计**：显示总请求数、成功率、平均响应时间
- **最近请求**：显示最近的AI请求记录
- **快捷操作**：快速启动/停止网关

### 4.2 AI服务管理

#### 添加服务

1. 点击"添加服务"按钮
2. 选择服务类型
3. 填写配置信息：
   - **名称**：服务的显示名称
   - **API地址**：服务的API地址
   - **API密钥**：您的API密钥
   - **模型**：要使用的模型列表
4. 点击"保存"

#### 编辑服务

1. 在服务列表中，点击服务名称
2. 修改配置信息
3. 点击"保存"

#### 删除服务

1. 在服务列表中，点击服务名称
2. 点击"删除"按钮
3. 确认删除

### 4.3 模型映射

模型映射允许您将一个模型名称映射到另一个模型。

#### 创建映射

1. 点击左侧菜单的"模型映射"
2. 点击"添加映射"按钮
3. 填写映射信息：
   - **源模型**：客户端请求的模型名称
   - **目标模型**：实际使用的模型名称
   - **Provider**：使用哪个AI服务
4. 点击"保存"

#### 使用映射

在客户端请求时，使用源模型名称，Silk会自动转换为目标模型。

### 4.4 请求日志

请求日志记录所有AI请求的详细信息：

- **请求ID**：唯一标识符
- **时间**：请求时间
- **AI服务**：使用的服务
- **模型**：使用的模型
- **状态码**：响应状态码
- **响应时间**：请求耗时
- **Token数**：输入/输出Token数

#### 查看日志

1. 点击左侧菜单的"请求日志"
2. 使用过滤器筛选日志
3. 点击日志条目查看详细信息

#### 导出日志

1. 点击"导出"按钮
2. 选择导出格式（CSV）
3. 保存文件

### 4.5 统计分析

统计分析显示以下信息：

- **请求趋势**：按时间显示请求数量
- **服务分布**：各AI服务的请求占比
- **模型分布**：各模型的请求占比
- **性能分析**：响应时间、Token使用等

### 4.6 设置

#### 基础设置

- **绑定地址**：网关监听的IP地址
- **端口**：网关监听的端口号
- **允许远程访问**：是否允许其他设备访问
- **开机自启**：系统启动时是否自动运行
- **自动启动网关**：Silk启动时是否自动启动网关
- **关闭时最小化**：点击关闭按钮时是否最小化到托盘

#### 高级设置

- **日志保留天数**：自动清理超过指定天数的日志
- **日志级别**：设置日志记录的详细程度
- **最大并发请求**：同时处理的最大请求数量
- **请求超时**：单个请求的最大处理时间
- **启用缓存**：是否缓存常用响应

#### 数据管理

- **导出配置**：备份当前配置
- **导入配置**：恢复配置
- **备份数据库**：备份本地数据库
- **恢复数据库**：恢复数据库

## 6. 故障排除

### 6.1 网关启动失败

**问题**：网关启动失败，提示端口被占用

**解决**：
1. 修改网关端口
2. 或关闭占用端口的程序

### 6.2 API密钥无效

**问题**：请求返回401错误

**解决**：
1. 检查API密钥是否正确
2. 检查API密钥是否过期
3. 重新生成API密钥

### 6.3 请求超时

**问题**：请求返回超时错误

**解决**：
1. 检查网络连接
2. 增加请求超时时间
3. 检查AI服务状态

### 6.4 响应格式错误

**问题**：客户端无法解析响应

**解决**：
1. 检查客户端配置是否正确
2. 检查API地址是否正确
3. 查看请求日志获取详细信息

1. 重启Silk
2. 修改端口
3. 关闭防火墙或添加例外

1. API密钥是否正确

3. API密钥是否有权限

1. 重新生成API密钥

3. 联系服务提供商

1. 网络连接

1. 检查网络带宽
2. 减少并发请求
3. 使用缓存

### Q1: 如何安装Silk？

**A**: 
1. 访问 [Silk官网](https://silk.dev) 下载对应系统的安装包
2. Windows：双击运行安装程序
3. macOS：将Silk拖到Applications文件夹
4. Linux：解压后运行 `./silk`

### Q2: 启动时提示"端口被占用"怎么办？

**A**: 
1. 修改Silk的端口号（设置 → 基础设置 → 端口）
2. 或者关闭占用端口的程序
3. 常用端口：1877（默认）、8080、3000

### Q3: 启动时提示"权限不足"怎么办？

**A**: 
1. Windows：右键点击Silk，选择"以管理员身份运行"
2. macOS/Linux：使用 `sudo` 命令运行

### Q4: 启动后界面空白怎么办？

**A**: 
1. 检查是否安装了最新版本
2. 清除浏览器缓存（如果是Web版本）
3. 重启应用
4. 检查系统日志获取错误信息

## 2. API密钥

### Q5: 如何获取API密钥？

**A**: 
- **OpenAI**：访问 [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
- **Claude**：访问 [console.anthropic.com/api-keys](https://console.anthropic.com/api-keys)
- **其他服务**：参考各服务的官方文档

### Q6: API密钥无效怎么办？

**A**: 
1. 检查密钥是否复制完整
2. 检查密钥是否过期
3. 检查账户是否有余额
4. 重新生成密钥

### Q7: 如何更新API密钥？

**A**: 
1. 点击左侧菜单的"AI服务"
2. 点击要更新的服务
3. 修改API密钥
4. 点击"保存"

### Q8: API密钥安全吗？

**A**: 
- Silk将API密钥加密存储在本地
- 不上传到任何服务器
- 仅在本地使用
- 建议定期更换密钥

## 3. 网关配置

### Q9: 如何启动网关？

**A**: 
1. 点击左侧菜单的"仪表盘"
2. 点击"启动网关"按钮
3. 等待启动成功
4. 记录显示的本地地址

### Q10: 网关启动失败怎么办？

**A**: 
1. 检查端口是否被占用
2. 检查防火墙设置
3. 检查权限是否足够
4. 查看错误日志

### Q11: 如何修改网关端口？

**A**: 
1. 点击左侧菜单的"设置"
2. 修改"端口"字段
3. 点击"保存"
4. 重启网关

### Q12: 如何允许远程访问？

**A**: 
1. 点击左侧菜单的"设置"
2. 开启"允许远程访问"
3. 点击"保存"
4. 重启网关

## 4. 使用问题

### Q13: 客户端无法连接怎么办？

**A**: 
1. 确认Silk已启动
2. 确认网关已启动
3. 检查API地址是否正确
4. 检查防火墙设置

### Q14: 请求返回401错误怎么办？

**A**: 
1. 检查API密钥是否正确
2. 检查API密钥是否过期
3. 检查账户是否有余额
4. 重新生成密钥

### Q15: 请求返回429错误怎么办？

**A**: 
1. 降低请求频率
2. 等待一段时间后重试
3. 升级API套餐
4. 使用多个API密钥

### Q16: 请求超时怎么办？

**A**: 
1. 检查网络连接
2. 增加请求超时时间
3. 检查AI服务状态
4. 减少并发请求

### Q17: 响应格式错误怎么办？

**A**: 
1. 检查客户端配置
2. 检查API地址
3. 查看请求日志
4. 确认协议兼容性

## 6. 高级功能

### Q22: 如何使用模型映射？

**A**: 
1. 点击左侧菜单的"模型映射"
2. 点击"添加映射"
3. 填写源模型和目标模型
4. 点击"保存"

### Q23: 如何配置多个AI服务？

**A**: 
1. 点击"添加服务"按钮
2. 添加多个AI服务
3. 配置模型映射
4. Silk会自动路由请求

### Q24: 如何实现负载均衡？

**A**: 
1. 添加多个相同类型的AI服务
2. 创建模型映射，源模型相同，目标Provider不同
3. Silk会自动进行负载均衡

### Q25: 如何实现故障转移？

**A**: 
1. 添加多个不同类型的AI服务
2. 创建模型映射，设置优先级
3. 当主服务不可用时，自动切换到备用服务

## 8. 性能优化

### Q31: 如何提高响应速度？

**A**: 
1. 启用缓存
2. 调整并发数
3. 使用本地网络
4. 选择合适的模型

### Q32: 如何减少Token使用？

**A**: 
1. 优化提示词
2. 使用经济实惠的模型
3. 设置最大Token限制
4. 监控Token使用量

### Q33: 如何降低延迟？

**A**: 
1. 使用就近的AI服务
2. 启用缓存
3. 减少并发请求
4. 使用快速模型

## 9. 安全问题

### Q34: 如何保护API密钥？

**A**: 
1. 不要分享API密钥
2. 定期更换密钥
3. 使用环境变量存储
4. 监控API使用情况

### Q35: 如何防止未授权访问？

**A**: 
1. 仅监听本地地址
2. 不开启远程访问
3. 使用防火墙
4. 定期检查日志

### Q36: 数据是否安全？

**A**: 
- 所有数据存储在本地
- 不上传到任何服务器
- 不收集用户数据
- 支持数据加密
