## 项目基本信息

| 字段 | 内容 |
|------|------|
| 项目名称 | Silk（丝路） |
| 项目定位 | 纯本地桌面 AI 多模型统一中转站 |
| 技术栈 | Tauri 2 + Vue 3 + Rust/Axum + SQLite |
| 目标用户 | 个人开发者 / AI 重度使用者 / AI 初学者 |

## V1 范围内（In Scope）

**刚性核心（全部已在当前代码中实现）：**

1. 本地 HTTP 网关中转（9 阶段管道 + 3 级回退）
2. 多协议双向互转（8 种协议适配器）
3. 多服务商渠道管理（CRUD + 连通性测试）
4. 多账户轮询（4 种策略）
5. 模型池管理映射（虚拟名 → 实际模型 + 多渠道路由）
6. Tauri 桌面端 UI（6 个路由视图）
7. 请求日志持久化与查看

**弹性细节（已完成部分保持）：**

8. Dashboard 统计、Agent 配置预设、设置页面、配置导入导出、系统托盘、插件系统、Token 统计

## 范围外（Out of Scope）

1. Web 管理后台
2. 多用户/团队协作
3. 云端同步/云存储
4. 分布式部署（Redis、消息队列等）
5. 移动端适配
6. 第三方插件市场
7. 实时日志流推送（WebSocket/SSE）
8. 自动健康检查轮询
